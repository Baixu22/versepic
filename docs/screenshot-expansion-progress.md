## 第三批：TF-0011 命名区域、TF-0012 导出控制、TF-0013 命名模板

### 用户入口与交付

- 「精确选区 → 命名区域」：新增、更新、重命名和删除预设。预设操作即时保存，取消对话框只取消当前选区修改；重置截图设置不删除明确保存的预设。

- 同一设置页提供文件名模板、项目名、日期子目录及命名示例。支持 date/time/timestamp/index/project/prefix/suffix；模板留空沿用既有命名。

- 这些设置影响保存文件，不改变剪贴板位图尺寸；文件引用指向处理后的文件。精确选区分别显示选区输出像素和处理后的文件像素。

### 实现与防护

- 保存任务在提交线程冻结不可变配置，编码线程不读取会变化的 QSettings；Qt/Pillow 各自使用真实编码参数。
- 文件先在目标目录临时编码，成功后原子替换；失败不覆盖原有图片，只清理本服务创建的空占位文件。后台保存失败通过 GUI 线程通知，手动保存失败保留截图会话供重试。
- 命名模板拒绝属性访问、索引访问和任意格式化；处理路径分隔符、控制字符和 Windows 保留名。唯一文件名通过排他创建分配，长模板截断掉序号后仍可安全产生后续名称。
- 命名区域保存在已有设置内，只含名称、坐标和显示器布局/DPI，不存截图像素。恢复时检查布局、比例与范围，失配不套用旧坐标，要求明确检查或更新。
- 损坏或未知版本的预设数据不被新记录覆盖；重名不隐式覆盖。当前上限为 100 个命名区域，名称 64 字符。
- 指定输出宽度支持 1～16384 px；新尺寸超过 100 MP 时明确失败，防止极端比例引起失控分配。原始尺寸路径不额外缩小图片。

- 绑定记录子窗口、根窗口、进程ID、指针位置和窗口矩形。每次发送前及等待期间检查身份、前台焦点、可见性、最小化状态、遮挡与位置；选区必须位于目标窗口内。
- 原生消息等待上限100ms；拒绝/忽略消息时以错误或未变化帧停止，绝不退回全局输入。Windows 消息坐标超出有符号16位范围时明确拒绝。
- Esc 的线程事件立刻阻止下一次滚动消息；已经进行中的系统调用或图像拼接可能先返回，指示器随后更新。屏幕取图后再次检查焦点和取消标记，未通过时不提交该帧；已经进入拼接计算的有效帧可能在停止前完成。
- 达到次数、时间、长度、已有会话像素上限、画面重复或匹配失败时停止。图片长度上限在拼接提交前再次检查，不先超限写入再撤销。
- 自动模式暂停原手动滚动采集定时器和横向 Shift 模拟逻辑，禁用会冲突的编辑按钮；停止后可以继续使用手动长截图。
- 捕获排除覆盖长截图框本体、工具栏和预览浮层，包括阴影范围，并等待桌面合成。修复了原生验收发现的框体阴影/焦点动画污染基准帧问题。

### 持久化与竞态保护

排除/恢复/重试/重识别使用BEGIN IMMEDIATE事务，将旧索引删除与令牌更新作为一个事务；每次异步任务认领新的令牌。结果写回同时核对item_id、image_id、状态和令牌。即使取消不能打断已进入原生OCR的调用，排除后再恢复也无法让旧结果写回新代任务。

删除条目会删除索引和状态；更换image_id/内容类型也清理旧索引。停止索引时使运行任务令牌失效并改回等待，下一次启动恢复上次中断任务，但不恢复失败/排除项。数据库仍以mode=rw连接，不因迟到结果重建已移动/删除的旧文件。

明确边界：排除删除的是应用当前逻辑索引，不是SQLite页面/WAL、外部备份或已复制文本的安全擦除；确认提示与README已说明。手动「识别文字」仍可供用户临时查看，但不会借此解除后台排除状态。

### 导出与安全

TSV使用标准csv模块的制表符分隔、CRLF行结束和双引号转义；含制表符/换行/双引号的单元格保持为一格。默认给去除前导空白后以=、+、-、@开头的内容加单引号，防止意外公式执行；这是可见开关，取消时明确允许原内容。它不等于所有表格软件自动类型转换都被阻止，日期/前导零需目标单元格文本格式配合。

Markdown导出使用当前已编辑表格，支持首行作为表头或生成Column序号；转义HTML、Markdown链接/图片/强调等标记、竖线、反斜杠，格内换行用br，制表符用字符实体，避免OCR文字作为远端图片或HTML被直接解释。文件使用QSaveFile原子提交，取消/写失败不损坏已有文件。

表格窗口不另行自动保存原图或OCR结果；用户主动复制的普通TSV仍可能被系统及应用正常剪贴板历史捕获。敏感截图仍由TF-0030的文字提取入口保护，未为它新增解除敏感策略的表格旁路。

### TF-0030 本机隔离能力实测（2026-10-10，本轮复测）

接力开始时先按记录继续 TF-0030，复测「独立 window station」这条路：
