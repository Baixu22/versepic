# Manage 页面优化方案与验收

## 设计方向

以剪贴板资料管理的「快速定位、安心编辑」为目标，采用克制的 shadcn/ui 风格，但仍使用原生 Qt Widgets。避免大标题、嵌套卡片、整页过渡、满屏 emoji 和装饰性统计。

- **颜色**：背景 `#FAFAFA`、工作区 `#FFFFFF`、正文 `#171717`、次级文字 `#737373`、边界 `#E5E5E5`；危险色仅用于删除。暗色沿用窗口作用域的语义色。
- **字体**：沿用系统中文字体和 Segoe UI；15px 工作区标题、13px 正文/导航、12px 辅助说明。文字与 16px 线性图标共享中心线和颜色状态，不用图片承载文字。
- **布局**：左侧轻量导航，右侧一块工作区。列表与编辑器共享 52px 顶部节奏；表单与底部动作区各自稳定，滚动不带走保存按钮。
- **交互**：方向键选择条目；显式新增入口；Ctrl+S 保存、Ctrl+N 新增；离开脏表单时确认；保存成功使用就地反馈。图标选择按需打开，使用委托绘制而不是创建几百个按钮。
- **性能与清晰度**：不引入 WebView、不做整页透明度合成。Qt 原生字体、矢量线性图标、DPR 感知截图，保留本地数据处理与按需渲染。

```text
 窗口标题                                         −  □  ×
 导航             ┌────────────────┬────────────────────────┐
 分组管理         │ 分组列表    ＋ │ 分组设置                │
 内容管理         ├────────────────┼────────────────────────┤
 导入/导出        │  分组 / 条目   │ 名称              图标 │
                  │  选中状态     │ 类型与行为说明          │
                  │               │                        │
                  │               ├────────────────────────┤
                  │               │ 删除    状态      保存 │
                  └────────────────┴────────────────────────┘
```

不采用大面积独立卡片和放大的页标题：这会抢占列表内容的层级。分组表单允许适度留白，而不是用低频 emoji 盘填满空间。导入导出按钮紧邻其说明与编码选择，不浮在页面另一端。

## 验收范围

原生 Windows Qt：浅色/深色，分组/文本/文件/导入导出，空状态，图标弹层，键盘操作，最小窗口，较大窗口，中英文，100%/150% 应用缩放及高 DPI。自动化覆盖保存、取消离开、字素完整性、默认按钮、列表选择和布局约束。验收结果完成后补充。
