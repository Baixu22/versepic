# 界面文案约定

与共用 Qt 组件一起维护，目标是让用户知道「这是什么、点击后会发生什么、接下来怎么做」。

- 同一功能使用同一名称：截图设置、钉图、剪贴板历史、普通分组、快速启动分组、隐藏分组、文字识别、选区控制点。
- 按钮写动作，如「新建分组」「选择文件…」「复制脱敏结果」。状态写结果，如「已复制」「导出完成」。
- 使用「设置」，避免与「设定」混用；历史条目统一称「记录」，不称「项目」或「他」。
- 说明优先写作用和适用范围，不解释线程、库名等实现细节。API 密钥、JSON 等配置必须用到的术语保留。
- 空状态给下一步；失败提示避免推测原因；删除提示明确对象、连带影响和无法撤销。
- 不承诺代码未实现的行为：CSV 只导出分组中的文本；普通分组的条目可复制或粘贴，具体动作取决于设置。
- 输入示例直接写「例如：常用回复」。静态占位文字不加省略号；处理中或还需打开选择器的动作使用「…」。
- 中文使用全角标点；中英文、数字之间保留适当空格。保留 `%1`、`%s`、`{count}` 等动态占位符。

## 代表性修改

| 原文案 | 调整后 |
| --- | --- |
| 截图设定 | 截图设置 |
| 确定要删除他吗？ | 删除这条记录？此操作无法撤销。 |
| 通用分组允许任意内容；选中条目后会向目标粘贴内容或文件 | 保存文字、图片和文件，方便再次复制或粘贴。 |
| 将所有保存的内容导出到 CSV 文件 | 将分组中的文本导出为 CSV，不包含图片和文件。 |
| 在后台线程中预加载 mss、画布、工具等模块 | 启动时在后台准备截图和标注功能。 |
| 选择项目后自动发送 Ctrl+V | 选择记录后，自动粘贴到目标窗口。 |
| 正在索引图片文字… | 正在准备图片文字搜索… |
| 是 / 否（通用确认框） | 确认 / 取消 |
| 自动（跟随系统）（下拉框中被截断） | 跟随系统 |

## 维护位置

使用 `main/translations/app_*.xml` 中的现有上下文统一修改显示文本，保留翻译键，
避免为文案调整重写业务逻辑。涉及功能范围的修正同步四种语言。
带换行的 source 必须与调用处一致：Python 的 `\n` 是实际换行时，XML 里也必须是实际换行。

发布前使用 Qt `lrelease` 编译对应 `.qm`，再验证调用上下文、占位符和实际窗口。
应用优先加载 `.qm`，仅修改 XML 不会更新正常运行时的显示。
